# Login Troubleshooting Guide

## Common Login Problems

If you are unable to log in, follow these troubleshooting steps.

### 1. Check your credentials

Make sure you are using the correct username and password.

Never share your password, API keys, tokens, or other sensitive information.

### 2. Clear browser cache and cookies

If the login page is not working correctly:

1. Open your browser settings.
2. Clear cached files and cookies for the application.
3. Close and reopen the browser.
4. Try logging in again.

### 3. Try another browser

If the issue continues, try accessing the application using another supported browser.

### 4. Contact support

If none of the above steps resolve the problem, contact the support team.

When contacting support, provide:

- A description of the problem
- Steps you already tried
- Browser and operating system information
- A screenshot with sensitive information removed

**Never include passwords, API keys, authentication tokens, or customer data.**
